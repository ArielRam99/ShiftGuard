# Security Policy

## Supported Versions

ShiftGuard is currently an MVP and does not publish versioned releases. Security
updates are applied to the latest revision on the `main` branch.

| Version | Supported |
| --- | --- |
| Latest `main` revision | Yes |
| Older revisions and forks | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ArielRam99/ShiftGuard/security/advisories/new).
Do not open a public issue or disclose the vulnerability publicly before a fix
is available.

Include the following information when possible:

- A description of the vulnerability and its potential impact
- The affected endpoint, component, or revision
- Reproduction steps or a minimal proof of concept
- Any suggested remediation

Do not include real employee records, credentials, access tokens, database
files, or other sensitive workforce data in a report. Use synthetic data when
demonstrating the issue.

You can expect an acknowledgement within five business days. After validation,
the maintainers will provide status updates as remediation progresses. Valid
reports will be addressed according to severity; reports that cannot be
reproduced or do not present a security risk may be closed with an explanation.

Please allow a reasonable remediation period before public disclosure. Once a
fix is available, the maintainers may publish an advisory describing the impact,
affected revisions, and upgrade guidance.
